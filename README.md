## 📌 What is This Project?

The Engineer's Codex is a collection of programming lessons organized as an online eBook.  
Each programming language is treated as its own "Volume" — like a series of books on a shelf.  
The entire project is built using only HTML and CSS to demonstrate mastery of web fundamentals.

## 📖 Volume I: The Skeleton (HTML) — 🟢 COMPLETED

### Chapters

| Ch | Title                    | Description                                                                                       |
|----|--------------------------|---------------------------------------------------------------------------------------------------|
| 1  | The Document Structure   | Understanding `<!DOCTYPE>`, `<html>`, `<head>`, and `<body>`. How browsers read your code.        |
| 2  | Semantic Tags            | Why `<header>`, `<nav>`, `<section>`, `<article>`, and `<footer>` matter for accessibility & SEO. |
| 3  | Text & Typography        | Headings (`<h1>`–`<h6>`), paragraphs, bold, italic, inline vs block elements.                     |
| 4  | Links & Navigation       | Anchor tags, relative vs absolute paths, opening links in new tabs.                               |
| 5  | Images & Media           | Embedding images, alt text, and understanding file formats (PNG, JPG, SVG).                       |
| 6  | Tables & Lists           | Ordered lists, unordered lists, and building data tables with `<table>`.                          |
| 7  | Forms & Inputs           | Text fields, buttons, checkboxes, radio buttons, and form submission basics.                      |

### Each Chapter Will Include

- A brief explanation of the concept
- A code example with syntax highlighting
- A flowchart or diagram for visual learners
- A summary box at the end of each chapter
