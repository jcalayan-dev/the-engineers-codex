Introduction

Every HTML document follows a specific structure—a blueprint that tells the browser how to read and display your content. Just like a building needs a foundation, walls, and a roof, an HTML page needs its core structural elements to function correctly.

In this chapter, you will learn the four essential building blocks that every HTML file must have. By the end, you will be able to create a valid HTML document from scratch and understand what each part does.

💡 Engineering Note

Browsers are very forgiving. If you miss a tag, they will try to "guess" your intent. However, for professional software engineering, we aim for valid code to ensure the page looks exactly the same across all devices and browsers.

Key Concepts

Element Purpose Required?
<!DOCTYPE html> Declares the document as HTML5. Yes
<html> The root element that wraps all content. Yes
<head> Contains metadata (Title, Charset, Styles). Yes
<body> Contains the visible content of the page. Yes

Code Example

Here is the minimum structure required for a valid web page. You can copy this template whenever you start a new HTML project.

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>My First Web Page</title> </head> <body> <h1>Welcome to the Codex</h1> <p>This content is visible to the user.</p> </body> </html>

Summary Checklist

  • The !DOCTYPE is always the very first line.
  • The html tag wraps everything.
  • The head is for the browser; the body is for the user.
  • Always close your tags (e.g., </body>).
