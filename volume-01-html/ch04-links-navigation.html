Introduction

Links are what make the World Wide Web a "web". Without them, every webpage would be an isolated island. In HTML, links are created using the Anchor tag (<a>).

In this chapter, you will learn how to connect your web pages together, how to link to external websites, and how to create special links that open email clients or jump to specific sections within the same page.

Key Concepts & Attributes

The anchor tag relies heavily on attributes — extra pieces of information added inside the opening tag that dictate how the element behaves.

Attribute / Syntax Purpose
href="..." "Hypertext Reference". The destination URL the link points to. This is mandatory.
target="_blank" Tells the browser to open the link in a new tab or window.
id="..." A unique identifier given to an element so a link can jump directly to it.
mailto: A URL scheme used in the href to open the user's default email client.
tel: A URL scheme used to trigger a phone call (especially useful on mobile devices).

Absolute vs. Relative URLs

When setting the href attribute, you can use either an absolute URL or a relative URL. Understanding the difference is critical for proper site architecture.

1. Absolute URLs

An absolute URL contains the full web address, including the protocol (https://) and the domain name. You use these when linking to an external website.

<!-- Linking to an external site requires an absolute URL --> <a href="https://github.com/jethneil">Visit my GitHub Profile</a>

2. Relative URLs

A relative URL points to a file within your own website's folder structure. It does not include the domain name. The browser calculates the path relative to the page the user is currently on.

<!-- Linking to a file in the same folder --> <a href="ch05-images-media.html">Next Chapter</a> <!-- Linking to a file in the parent folder (going up one level) --> <a href="../index.html">Back to Bookshelf</a> <!-- Linking to a file inside a sub-folder --> <a href="assets/cheatsheet.pdf">Download PDF</a>

Opening Links in a New Tab

If you are linking to an external site, you often want to keep your own site open in the background. You achieve this using the target="_blank" attribute.

🛡️ Security Best Practice

When using target="_blank", always include rel="noopener noreferrer". This prevents the newly opened page from gaining access to the original page's browser session, protecting your site from a specific type of cyber attack called "tabnabbing".

<!-- Safe way to open an external link in a new tab --> <a href="https://allegromicro.com" target="_blank" rel="noopener noreferrer"> Visit Allegro MicroSystems </a>

Page Jumps (Internal Anchors)

You can create links that jump to a specific section on the same page. This is exactly how the "Table of Contents" on Wikipedia works.

To do this, you first give the target element a unique id. Then, you set the link's href to that ID, preceded by a hash symbol (#).

<!-- Step 1: Create the target with an ID --> <h2 id="conclusion">Chapter Conclusion</h2> <p>This is the bottom of the page.</p> <!-- Step 2: Create a link pointing to that ID --> <a href="#conclusion">Jump to Conclusion</a>

Email and Phone Links

HTML allows you to trigger applications natively installed on the user's device. Using the mailto: scheme opens their email client, and the tel: scheme prompts their phone to make a call.

<!-- Email Link (Opens Outlook, Apple Mail, etc.) --> <a href="mailto:jethneil@example.com">Email Me</a> <!-- Email link with a pre-filled subject line --> <a href="mailto:jethneil@example.com?subject=Portfolio%20Inquiry"> Send Inquiry </a> <!-- Phone Link (Triggers dialer on mobile devices) --> <a href="tel:+1234567890">Call: (123) 456-7890</a>

Accessibility: Writing Good Link Text

Link text (the clickable words) should always clearly describe the destination. Screen reader users often bring up a list of all links on a page to navigate quickly. If every link says "Click Here", the list is completely useless to them.

<!-- ❌ BAD: Vague and inaccessible --> <p>To view my portfolio, <a href="portfolio.html">click here</a>.</p> <!-- ✅ GOOD: Descriptive and accessible --> <p>You can view my past work in my <a href="portfolio.html">engineering portfolio</a>.</p>

📋 Chapter Summary

  • The <a> (anchor) tag is used to create links.
  • The href attribute defines the destination of the link.
  • Use Absolute URLs for external sites (e.g., https://google.com).
  • Use Relative URLs for pages within your own site (e.g., about.html).
  • Use target="_blank" with rel="noopener noreferrer" to safely open external links in a new tab.
  • Use href="#id-name" to jump to a specific section on the same page.
  • Always write descriptive link text instead of generic phrases like "click here".
