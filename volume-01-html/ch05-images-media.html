Introduction

While text forms the structural foundation of the web, media—such as images, audio, and video—brings it to life. Unlike text, which is written directly inside the HTML file, media files are stored separately and embedded into the page using specific tags.

In this chapter, you will learn how to properly insert images using the <img> tag, why the alt attribute is critical for engineering a professional website, and how to embed modern audio and video players natively without relying on third-party plugins.

💡 Engineering Note

The <img> tag is what we call an empty element (or self-closing tag). Because it embeds an external file rather than wrapping around text, it does not have a closing tag like </img>.

The Image Tag & Attributes

To display an image, you only need the <img> tag and two mandatory attributes:

Attribute Purpose Example
src "Source". The path or URL to the image file. This tells the browser where to find the picture. src="assets/logo.png"
alt "Alternative text". A text description of the image used for screen readers and SEO. alt="Allegro MicroSystems Logo"
width / height Sets the dimensions of the image in pixels (without adding "px"). Helps prevent layout shifts. width="500" height="300"
loading Can be set to lazy to defer loading the image until the user scrolls near it (improves performance). loading="lazy"

Embedding Images

Here is how you put it all together to display an image properly. Notice how we include both src and alt text.

<!-- Basic image embed --> <img src="assets/profile-photo.jpg" alt="Portrait of Jethneil Joem Calayan"> <!-- Image with dimensions and lazy loading for better performance --> <img src="assets/yield-chart.png" alt="Bar chart showing 98% yield improvement" width="800" height="400" loading="lazy">

Choosing the Right Image Format

As a software engineer, choosing the correct file format is crucial for site speed and performance. Here is a quick guide on what format to use and when:

Format Best Used For Characteristics
JPEG / JPG Photographs and complex images with many colors. Lossy compression (loses quality to save file size). No transparency.
PNG Graphics, logos, and screenshots. Lossless compression (high quality). Supports transparent backgrounds.
SVG Icons, logos, and simple illustrations. Vector-based (math equations, not pixels). Scales infinitely without losing quality.
WebP Modern web images (both photos and graphics). Excellent compression (smaller files than JPEG/PNG). Supported by all modern browsers.
GIF Simple, short animations. Limited to 256 colors. Not recommended for static images anymore.

Accessibility: The Golden Rule of alt Text

The alt attribute is not optional if you want to build professional websites. It serves three critical purposes:

  • Screen Readers: Visually impaired users will hear the alt text read aloud.
  • Broken Links: If the image file fails to load, the browser will display the alt text in its place so the user still understands what should be there.
  • SEO: Search engines like Google cannot "see" images, so they read the alt text to index your content.
<!-- ❌ BAD: Filename used as alt text (unhelpful to screen readers) --> <img src="img4829.jpg" alt="img4829.jpg"> <!-- ❌ BAD: Redundant phrases --> <img src="dog.jpg" alt="A picture of a dog"> <!-- ✅ GOOD: Descriptive and concise --> <img src="dog.jpg" alt="A golden retriever catching a frisbee in the park">
Pro Tip

If an image is purely decorative (like a background pattern or a swirly line) and adds no meaning to the content, you should leave the alt attribute completely empty like this: alt="". This tells screen readers to safely skip over it.

Embedding Audio and Video

HTML5 introduced native tags for embedding media without needing third-party plugins like Flash. The <audio> and <video> tags work very similarly to the image tag, but they require a closing tag and often use the controls attribute to display play/pause buttons.

<!-- Embedding an Audio file --> <audio controls> <source src="assets/podcast-interview.mp3" type="audio/mpeg"> Your browser does not support the audio element. </audio> <!-- Embedding a Video file --> <video controls width="800" poster="assets/video-thumbnail.jpg"> <source src="assets/demo-reel.mp4" type="video/mp4"> Your browser does not support the video tag. </video>

📋 Chapter Summary

  • The <img> tag is self-closing and embeds external image files.
  • Always include the src (where the file is) and alt (what the image is) attributes.
  • Use JPEG for photos, PNG for graphics with transparency, and SVG for scalable logos.
  • Write descriptive alt text for accessibility, but leave it blank (alt="") for purely decorative images.
  • Use <audio> and <video> tags with the controls attribute to embed native media players.
