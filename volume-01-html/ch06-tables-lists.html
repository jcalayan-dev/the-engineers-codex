Introduction

Data organization is a core part of engineering. When presenting information on the web, you often need to group related items or display multi-dimensional data. HTML gives us two primary tools for this: Lists (for sequential or grouped items) and Tables (for grid-based data).

In this chapter, you will learn how to create bulleted, numbered, and definition lists, as well as how to architect a semantically correct data table.

💡 Historical Note

In the late 1990s and early 2000s, web developers used HTML tables to build entire website layouts. This was a terrible practice for accessibility and maintenance! Today, tables should only be used for presenting tabular data (like spreadsheets or schedules), never for page layout.

HTML Lists

There are three main types of lists in HTML. Every list requires a "parent" tag to define the type of list, and "child" tags to define the individual items.

List Type Parent Tag Item Tag Visual Result
Unordered List <ul> <li> (List Item) Bullet points (•)
Ordered List <ol> <li> (List Item) Numbered sequence (1, 2, 3...)
Description List <dl> <dt> (Term) & <dd> (Description) Dictionary-style formatting

Unordered and Ordered Lists

Use an unordered list (<ul>) when the sequence of items does not matter (like a grocery list). Use an ordered list (<ol>) when the sequence is important (like a step-by-step recipe or tutorial).

<!-- Unordered List Example --> <h3>Frontend Technologies</h3> <ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul> <!-- Ordered List Example --> <h3>Deployment Steps</h3> <ol> <li>Write the code.</li> <li>Commit to Git.</li> <li>Push to GitHub.</li> </ol>

Description Lists

A description list (<dl>) is perfect for glossaries, FAQs, or metadata. It pairs a term (<dt>) with its definition (<dd>).

<dl> <dt>Semiconductor</dt> <dd>A material that has an electrical conductivity between a conductor and an insulator.</dd> <dt>Yield</dt> <dd>The percentage of non-defective items produced in a manufacturing process.</dd> </dl>

HTML Tables

Tables are used to display grid data. Creating a table requires nesting several different tags to build the rows, headers, and individual data cells.

Tag Meaning Description
<table> Table The parent container for the entire table.
<tr> Table Row Defines a single horizontal row.
<th> Table Header A cell used for column or row headings. Browsers render this as bold and centered.
<td> Table Data A standard cell containing the actual data.

A Basic Table Structure

Tables are built row by row. You create a <tr>, and inside it, you place your <th> or <td> cells.

<table> <!-- Row 1: The Headers --> <tr> <th>Language</th> <th>Type</th> <th>Difficulty</th> </tr> <!-- Row 2: First set of data --> <tr> <td>HTML</td> <td>Markup</td> <td>Easy</td> </tr> <!-- Row 3: Second set of data --> <tr> <td>C++</td> <td>Programming</td> <td>Hard</td> </tr> </table>

Semantic Table Sections

For complex tables, you should group your rows into semantic sections using <thead> (header), <tbody> (body), and <tfoot> (footer). This helps screen readers understand the table's structure and allows developers to style the header independently from the data rows.

<table> <thead> <tr> <th>Quarter</th> <th>Yield %</th> </tr> </thead> <tbody> <tr> <td>Q1</td> <td>94.5%</td> </tr> <tr> <td>Q2</td> <td>96.2%</td> </tr> </tbody> <tfoot> <tr> <th>Average</th> <td>95.35%</td> </tr> </tfoot> </table>

Merging Cells (Colspan and Rowspan)

Sometimes a cell needs to stretch across multiple columns or down across multiple rows. You can achieve this using the colspan and rowspan attributes directly on a <th> or <td> tag.

<!-- This header cell stretches across 2 columns --> <th colspan="2">Financial Data 2026</th> <!-- This data cell stretches down across 3 rows --> <td rowspan="3">Category A</td>

📋 Chapter Summary

  • Use <ul> for bulleted lists and <ol> for numbered lists. Both use <li> for items.
  • Use <dl> for glossary-style lists with terms (<dt>) and descriptions (<dd>).
  • Never use tables for page layout — only for tabular data.
  • Tables are built row by row using <tr>, containing headers (<th>) and data cells (<td>).
  • Use <thead>, <tbody>, and <tfoot> to logically segment complex tables.
  • Use colspan and rowspan attributes to merge cells horizontally or vertically.
