Introduction

Forms allow you to collect data from the user and send it to a server. Whether it's a login screen or a search bar, forms are the primary engine of web interactivity.

💡 Engineering Note

HTML forms only collect data. Processing that data (saving to a database) requires a backend language like Python or Java, which we will cover in later volumes.

The Form Element & Core Tags

TagPurpose
<form>The container for all input elements.
<input>The most versatile element (text, password, etc.).
<label>Defines a text label for an input (Critical for A11y).
<button>Clickable element to submit the form.

Input Types

<!-- Text and Password --> <input type="text"> <input type="password"> <!-- Selection Types --> <input type="checkbox"> <input type="radio" name="choice">

A Complete Form Example

<form action="#" method="POST"> <label for="name">Name:</label> <input type="text" id="name" name="user" required> <label for="msg">Message:</label> <textarea id="msg" name="message"></textarea> <button type="submit">Send Data</button> </form>
