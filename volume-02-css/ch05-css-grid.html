Introduction

If Flexbox is a "string" of elements, CSS Grid is a "blueprint." CSS Grid Layout is the most powerful layout system available in CSS. It is a 2-dimensional system, meaning it can handle both columns and rows at the same time, unlike Flexbox which is largely a 1-dimensional system.

In this chapter, we will learn how to define a grid coordinate system on a parent container and place child elements exactly where they belong. We will also explore the Fractional Unit ($fr$), an engineering-focused unit that allows us to divide available space into proportional segments without complex percentage math.

Key Concepts

Concept Definition Engineering Role
Grid Container The parent element where display: grid is applied. The coordinate system for the layout.
Grid Track The space between two grid lines (either a row or a column). The "pathway" for content.
Grid Cell The intersection of a grid row and a grid column. The smallest unit of the grid.
fr Unit A fractional unit representing a portion of the free space. Enables proportional, flexible sizing.
Gap The gutter or space between grid tracks. Controls information density.

1. The Mathematics of Space: The $fr$ Unit

One of the most innovative features of CSS Grid is the fr unit. It allows you to set the size of a track as a fraction of the free space in the grid container. This eliminates the need for calculating percentages ($%$) or pixels ($px$).

Proportional Logic:

$$Total Width = \sum (n \cdot fr) + \sum Gaps$$

If you define columns as 1fr 2fr 1fr, the middle column will always be exactly twice as wide as the outer columns, regardless of the total width of the screen.

2. Defining the Blueprint

To build a grid, you define the tracks on the container. You can use the repeat() function to simplify repetitive patterns.

/* 1. Define a 3-column grid */ .grid-wrapper { display: grid; grid-template-columns: 200px 1fr 1fr; grid-template-rows: repeat(3, 100px); gap: 20px; } /* 2. Precise placement of an item */ .sidebar { grid-column: 1 / 2; /* Starts at line 1, ends at line 2 */ grid-row: 1 / 4; /* Spans all 3 rows */ }

4. Decision Matrix: Grid or Flexbox?

A Senior Engineer knows that these tools are complementary. Use this logic to decide which to apply:

RequirementRecommended Tool
Overall page structure (Layout)CSS Grid
Complex alignment in two directionsCSS Grid
Simple row or column of itemsFlexbox
Centering a single elementFlexbox
Alignment within a component (e.g. Nav bar)Flexbox

📋 Chapter Summary

  • CSS Grid is a 2D layout system for rows and columns.
  • The fr unit makes flexible, proportional sizing simple and mathematical.
  • Use grid-template-columns and rows to define your blueprint.
  • Items are placed using Grid Lines (e.g., 1 / 3 spans two tracks).
  • Combine Grid for the "Big Picture" and Flexbox for "Small Components" to achieve professional-grade UI architecture.
